# Ясно для Windows 11

Переключатель раскладки для Windows 11 (x64): та же логика, что в Mac-версии, и те же словари.
Пример: в английской раскладке набрано `ghbdtn` — после пробела в поле окажется «привет», а раскладка станет русской.

Это первая, проверочная версия (0.1.0). Работу в настоящих приложениях нужно проверить на Windows 11, ниже есть список.

## Запуск

1. Скачайте `Yasno-windows-x64` из последней сборки во вкладке **Actions** → **Windows** репозитория и распакуйте.
2. Запустите `Yasno.exe`. Окна нет: появится значок «Ясно» в области уведомлений (возможно, под стрелкой ^).
3. Windows SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае». Сборка пока не подписана.
4. Наберите в Блокноте в английской раскладке `ghbdtn ` — ожидается «привет ».

Права администратора не нужны. Разрешений, как на Mac, Windows не спрашивает.

## Что умеет

- Исправление слова после пробела и во время набора (от четырёх букв), короткие слова после паузы 0,6 с — те же правила, что на Mac (`windows/core` — построчный перенос `Sources/SwitchCore`).
- Короткое нажатие Shift: отменяет последнюю автоматическую замену; со словом — преобразует его в следующую раскладку по кругу; в пустом месте — просто переключает раскладку (EN → RU → UK).
- Адреса сайтов: `фссщгтеюфзздуюсщь` → `account.apple.com`.
- Опечатки (флажок «Исправлять опечатки» в меню значка), в том числе с системной проверкой орфографии Windows, если для языка установлен словарь.
- Пауза, исключение текущего приложения, автозапуск — в меню значка (правая кнопка мыши).
- Поля паролей не редактируются (проверка через UI Automation).
- По умолчанию исключены терминалы (Windows Terminal, cmd, PowerShell), менеджеры паролей и удалённый рабочий стол.

Таблицы раскладок программа читает из самой Windows (`ToUnicodeEx`), поэтому подходят «Русская», «Украинская» и «Украинская (расширенная)», «США», «Немецкая» и другие английские раскладки.

## Как устроена замена

Windows не даёт надёжно читать текст в чужих полях, поэтому замена делается так же, как в Mac-версии для Google Docs: Backspace по числу набранных символов и ввод нужного текста (Unicode), затем смена раскладки окна. Клавиши, нажатые во время этой короткой операции, удерживаются и отправляются после неё. Клик мышью, стрелки, сочетания с Ctrl/Alt/Win и смена окна сбрасывают текущее слово.

Нажатия обрабатываются только в памяти: ничего не пишется на диск и не отправляется в сеть.

## Диагностика

```
Yasno.exe --diagnose
```

Покажет найденные раскладки, языки системной проверки орфографии и размеры словарей, без пользовательского текста.

## Что проверить на Windows 11

1. Блокнот, Word, Chrome/Edge (обычное поле, Google Docs), Telegram: `ghbdtn ` → «привет », `руддщ ` → «hello ».
2. Во время набора: `gthtrk.xfkbcm` → «переключались» без пробела.
3. Shift: после автозамены — отмена; на слове — круг EN → RU → UK; в пустом поле — смена раскладки.
4. Быстрый набор фразы целиком, без потери и перестановки букв.
5. Поле пароля (например, вход на сайт): ничего не меняется.
6. Меню значка: пауза, опечатки, исключение приложения, автозапуск.

## Сборка

Логика собирается и тестируется на любой системе:

```sh
cd windows
cargo test -p yasno-core
```

Приложение собирается под Windows (`cargo build --release -p yasno`) или кросс-компиляцией из Linux:

```sh
rustup target add x86_64-pc-windows-gnu   # и пакет gcc-mingw-w64-x86-64
cargo build --release -p yasno --target x86_64-pc-windows-gnu
```

GitHub Actions (`.github/workflows/windows.yml`) на каждом изменении `windows/` собирает `.exe` на Windows, прогоняет тесты и сверяет встроенные таблицы раскладок с настоящими таблицами Windows.

## Выпуск

Mac-версия обновляется из последнего релиза GitHub (`releases/latest`). Windows-релизы поэтому публикуются с тегом `win-v0.1.0` и **без** отметки Latest, иначе автообновление на Mac сломается.

## Пока нет

- Автообновления (будет по тегам `win-v…`).
- Окна настроек и списка слов-исключений (исключения можно задать в реестре: `HKCU\Software\Yasno\IgnoredWords`, через `;`).
- Подписи кода (без неё SmartScreen предупреждает при первом запуске).
- Работы в окнах, запущенных от администратора: Windows не пускает туда ввод от обычной программы.
- Сборки для ARM64.
