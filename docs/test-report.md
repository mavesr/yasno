# Проверка «Ясно» — история до 0.1.4

Дата: 17 октября 2026. Среда: macOS 27.0.1, Apple Silicon, Google Chrome.
Источники ввода: ABC, Russian, Ukrainian – Legacy. Немецкий использует ABC.

Текущая версия **0.1.4**: **46 тестов, 0 ошибок**, проверены исправления аудита и 12 быстрых системных прогонов в Chrome. [Подробный отчёт 0.1.4](audit-fixes.md). Ниже сохранены результаты предыдущих версий.

## Автоматические проверки

`swift test`: **34 теста, 0 ошибок**. Проверены словари, фактические таблицы раскладок Apple, различия Ukrainian Legacy / Russian, сохранение регистра, корректные слова всех четырёх языков, исключения и служебные строки, неоднозначные общие слова, небуквенные окончания, NBSP в браузере, ручное преобразование и полный круг раскладок. Восемь проверок одиночного Shift покрывают оба Shift, заглавные буквы и выделение, другие модификаторы, долгое удержание, пересечение двух Shift, повторные события, смену фокуса и два самостоятельных нажатия. Ещё восемь регрессионных проверок покрывают короткие слова, менее частые словоформы, выбор RU/UK по соседнему тексту, границы контекста, сохранение правильных коротких слов четырёх языков и целую смешанную фразу.

Сборка release завершилась успешно. Подпись установленного приложения проверена командой `codesign --verify --deep --strict`.

## Системный ввод в Chrome

Использована локальная страница `browser-test.html` с input, textarea и contenteditable. Драйвер `scripts/input-test.swift` отправляет события через `cghidEventTap`, поэтому проверка проходит через глобальный перехватчик приложения. Обычный ввод через средства браузерной автоматизации может обходить этот перехватчик и не подходит для такой проверки.

Перед вводом драйвер проверяет Chrome, заголовок собственной тестовой страницы и тип активного поля. Образцы и клавиши фиксированы; Enter не используется. Никакие формы не отправляются. В приложении драйвер отсутствует и для обычной работы не требуется.

| Сценарий | Результат |
|---|---|
| ABC → русский, `ghbdtn ` в input и contenteditable | `привет `, выбирается Russian |
| ABC → украинский, `ghsdbn ` в input | `привіт `, выбирается Ukrainian Legacy |
| Корректное украинское `привіт ` | Сохраняется, остаётся Ukrainian |
| Корректное русское `привет ` | Сохраняется, остаётся Russian |
| Russian → английский, `руддщ ` в textarea | `hello `, выбирается ABC |
| Russian → немецкий, `пгеут ` в textarea | `guten `, выбирается ABC |
| Двойной Shift после автоматической замены | Возвращает исходное слово и раскладку |
| Выделенное `привет мир` + двойной Shift | `ghbdtn vbh`, выбирается ABC |
| Быстрый набор двух слов с продолжением во время исправления | `привет мир `, без потерянных символов |
| NBSP в конце строки contenteditable | Исправление работает, NBSP сохраняется |

Перечисленные базовые сценарии проверены в версии 0.1. После исправления двойного Shift в установленной версии 0.1.1 отдельно проверены системными событиями:

| Сценарий | Результат |
|---|---|
| Пустое поле, три двойных Shift из ABC | Russian → Ukrainian → ABC; поле остаётся пустым |
| Ручное `lj,hjuj`, последовательные двойные Shift | `доброго` / Russian → `доброго` / Ukrainian → `lj,hjuj` / ABC; без дублирования |
| Автоматическое `lj,hjuj ` при предпочтении UK | `доброго ` / Ukrainian |
| Двойной Shift после этой автозамены | `lj,hjuj ` / ABC, отмена сохранена |
| Следующие двойные Shift после отмены | `доброго ` / Russian → `доброго ` / Ukrainian → `lj,hjuj ` / ABC |
| Ручное `ghbdtn`, полный круг | `привет` / Russian → `прівет` / Ukrainian Legacy → `ghbdtn` / ABC |

Вариант `прівет` — буквальное восстановление тех же физических клавиш в Ukrainian Legacy; ручное переключение не переводит и не исправляет орфографию.

В версии 0.1.2 двойной Shift заменён одним коротким нажатием. В установленной release-сборке проверены системными событиями в Chrome:

| Сценарий | Результат |
|---|---|
| Пустое поле: левый Shift, правый Shift, левый Shift | ABC → Russian → Ukrainian → ABC, поле пустое |
| Левый и правый Shift с буквой H | Вводится `HH`, остаётся ABC; проверено в input и textarea |
| Shift + стрелка влево | Выделен один символ, остаётся ABC |
| Shift удерживается 0,6 секунды | Без переключения |
| Оба Shift одновременно | Без переключения |
| Shift с Control в обоих порядках нажатия | Без переключения |
| Автоматическое `ghbdtn ` → `привет `, затем один Shift | `ghbdtn `, выбирается ABC |
| Следующие одиночные Shift после отмены | Russian → Ukrainian → ABC, исходная строка восстановлена |
| Ручное `lj,hjuj`, два одиночных Shift | `доброго` / Ukrainian → `доброго` / Russian, без дублирования |

Распознавание жеста не задерживает и не поглощает Shift. Команда выполняется на отпускании, только если нажатие длилось не более 0,4 секунды и не сопровождалось другим вводом. Длительность берётся из временных меток событий, чтобы короткая очередь на время замены текста не превратила долгое удержание в короткое. Отдельное повторное нажатие — следующий переход; специального жеста двойного Shift больше нет. В contenteditable дополнительно подтверждены полный круг, отсутствие переключения после долгого удержания и ввод заглавной `H`.

## Короткие слова и быстрый набор в 0.1.3

Первоначальные тесты воспроизвели отсутствие исправления `zr`, `ns` и «короткімі». Найдены ограничения: минимум три символа; порог 25 000, исключавший «короткими» с рангом 37 745; редкие сокращения и буквы чужого алфавита в частотных списках; отложенное начало обработки на 35 мс, за которое следующая буква могла отменить проверку.

Теперь двухбуквенные кандидаты должны входить в первые 2 000 слов. Частые правильные исходные слова сохраняются; для редкого исходного сокращения требуется преимущество кандидата минимум в 40 раз. Алфавит проверяется отдельно для языка. Неоднозначные RU/UK кандидаты разрешаются по ближайшим шести словам текущего предложения, затем по ручному предпочтению. Для слов от четырёх букв используется весь словарь. Последующий ввод удерживается уже на границе слова и последовательно воспроизводится после проверки; повторные границы в очереди тоже обрабатываются.

В установленной release-сборке системными событиями Chrome проверено:

| Сценарий | Результат |
|---|---|
| Физические клавиши `ghbdtn how are you zr ns ct,t gjxedf'i `, старт ABC, input | `привет how are you як ти себе почуваєш `, итог Ukrainian |
| Та же фраза, textarea, интервал 15 мс между всеми клавишами | Вся фраза совпадает точно, потерь или перестановок нет |
| В поле уже `як `, выбран ABC, прежнее ручное предпочтение Russian; ввод `ns ` | `як ти `, выбирается Ukrainian |
| Russian-клавиши «короткими программы» при старте в Ukrainian Legacy, contenteditable | `короткими программы `, итог Russian |
| Отдельное «программи» в Ukrainian Legacy | `программы `, выбирается Russian |
| Один Shift после последнего исправления | Возвращается `программи ` и Ukrainian; NBSP сохранён |

Драйвер проверяет не только раскладку, но и точное содержимое тестового поля. Для contenteditable нормализуются только NBSP и узкий NBSP при сравнении пробелов.

Перестановка букв в «проргамми» не устраняется преобразованием раскладки: полученное «проргаммы» тоже содержит опечатку. Обычная орфографическая автозамена не добавлялась.

## Защищённый ввод

В браузерном поле пароля подтверждены `IsSecureEventInputEnabled() == true` и защищённый подтип Accessibility. Кириллической автозамены вымышленного тестового ввода не наблюдалось. Все тестовые значения очищены.

Системный драйвер в защищённом поле создавал строку другой длины, чем заданный образец; контроль с полностью завершённым приложением дал ту же длину. Поэтому буквальную точность синтетического ввода в защищённом поле этот тест не подтверждает. Для обычных текстовых полей проверены и результат, и полнота ввода.

## Практические ограничения

- Автоматика пропускает одиночные буквы, неизвестные слова и неразрешённые неоднозначности. Двухбуквенные слова требуют более сильных оснований, чем длинные.
- Для неоднозначных RU/UK вариантов учитываются ближайший контекст и ручное предпочтение; без достаточных оснований замена пропускается.
- Enter может отправлять сообщение, поэтому исправление запускается пробелом или пунктуацией, а не после отправки.
- Сложные редакторы документов, терминалы, удалённые рабочие столы и другие браузеры отдельно не проверялись. Поля без подходящих Accessibility-диапазонов пропускаются.
- Проверки не заменяют длительную эксплуатацию: это первая локальная версия.
