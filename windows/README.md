# Ясно для Windows 11

Переключатель раскладки для Windows 11 (x64): та же логика, что в Mac-версии, и те же словари.
Пример: в английской раскладке набрано `ghbdtn` — после пробела в поле окажется «привет», а раскладка станет русской.

Версия 0.2.0 переделана по образцу Mac-версии: клавиши, нажатые во время проверки слова, держатся и отправляются по порядку после замены, поэтому быстрый набор больше не теряет и не переставляет буквы. Есть окно настроек и автообновление.

## Установка

1. Скачайте `yasno-0.2.0-x64.exe` (или архив `Yasno-windows-0.2.0-x64.zip`) из релиза `win-v0.2.0` на странице Releases репозитория.
2. Запустите. Windows SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае». Сборка не подписана.
3. Ясно само установится в `%LOCALAPPDATA%\Programs\Yasno`, добавится в меню «Пуск» и в автозапуск и откроет окно настроек. Значок живёт в области уведомлений (возможно, под стрелкой ^): левая кнопка — окно, правая — меню.
4. Наберите в Блокноте в английской раскладке `ghbdtn ` — ожидается «привет ».

Права администратора не нужны. Скачанный файл после первого запуска можно удалить.

## Обновление

Как на Mac: каждый день в 21:00 (или через 5 минут после запуска, если проверка была пропущена) Ясно смотрит релизы `win-v…` на GitHub, скачивает новый `.exe`, сверяет SHA-256, заменяет себя и перезапускается. Выключается флажком «Обновлять автоматически», вручную — «Проверить сейчас».

## Что умеет

- Исправление слова после пробела и во время набора (от четырёх букв), короткие слова после паузы 0,6 с — те же правила, что на Mac (`windows/core` — построчный перенос `Sources/SwitchCore`).
- Короткое нажатие Shift: отменяет последнюю автоматическую замену; со словом — преобразует его в следующую раскладку по кругу; в пустом месте — просто переключает раскладку (EN → RU → UK).
- Адреса сайтов: `фссщгтеюфзздуюсщь` → `account.apple.com`.
- Опечатки (флажок «Исправлять опечатки» в окне), в том числе с системной проверкой орфографии Windows, если для языка установлен словарь.
- Окно настроек как на Mac: состояние, «Включено», опечатки, автозапуск, исключения (слова и программы), обновления, счётчик исправлений.
- Пауза, исключение текущего приложения, проверка обновлений — в меню значка.
- Запятая и точка русской/украинской раскладки — это клавиши `?` и `/` английской: `ghbdtn?` → «привет,».
- Поля паролей не редактируются (проверка через UI Automation).
- По умолчанию исключены терминалы (Windows Terminal, cmd, PowerShell), менеджеры паролей и удалённый рабочий стол.

Таблицы раскладок программа читает из самой Windows (`ToUnicodeEx`), поэтому подходят «Русская», «Украинская» и «Украинская (расширенная)», «США», «Немецкая» и другие английские раскладки.

## Как устроена замена

Windows не даёт надёжно читать текст в чужих полях, поэтому замена делается Backspace по числу набранных символов и вводом нужного текста (Unicode), затем окно переключает раскладку. Движок (`windows/core/src/engine.rs`) повторяет правила Mac-версии (`KeyboardMonitor`):

- слово, которое знает Ясно, всегда совпадает с тем, что дошло до программы, клавиша в клавишу;
- после пробела следующие клавиши держатся, пока проверка не закончится и замена не будет сделана, затем отправляются по порядку;
- после всего, что отправило Ясно, клавиши держатся, пока отправленное не вернётся через перехват: иначе нажатие, ещё не дошедшее до перехвата, обогнало бы замену;
- удержанные буквы отправляются текстом в той раскладке, в которой их считает Ясно, пока окно не подтвердит новую раскладку; если окно её так и не включит, слово всё равно допечатается правильно;
- сторож отпускает всё как набрано, если проверка зависла.

Окна, запущенные от администратора, Ясно не трогает: Windows не пускает туда ввод от обычной программы, и удержанные клавиши потерялись бы.

Нажатия обрабатываются только в памяти: ничего не пишется на диск и не отправляется в сеть (кроме проверки обновлений на GitHub).

## Диагностика

```
Yasno.exe --diagnose
```

Покажет найденные раскладки, языки системной проверки орфографии и размеры словарей, без пользовательского текста.

## Что проверить на Windows 11

1. Блокнот, Word, Chrome/Edge (обычное поле, Google Docs), Telegram: `ghbdtn ` → «привет », `руддщ ` → «hello ».
2. Во время набора: `gthtrk.xfkbcm` → «переключались» без пробела.
3. Shift: после автозамены — отмена; на слове — круг EN → RU → UK; в пустом поле — смена раскладки.
4. Быстрый набор фразы целиком, без потери и перестановки букв.
5. Поле пароля (например, вход на сайт): ничего не меняется.
6. Меню значка: пауза, опечатки, исключение приложения, автозапуск.

## Сборка

Логика собирается и тестируется на любой системе:

```sh
cd windows
cargo test -p yasno-core
```

Приложение собирается под Windows (`cargo build --release -p yasno`) или кросс-компиляцией из Linux:

```sh
rustup target add x86_64-pc-windows-gnu   # и пакет gcc-mingw-w64-x86-64
cargo build --release -p yasno --target x86_64-pc-windows-gnu
```

## Тесты

- `cargo test -p yasno-core` — детектор (перенос тестов Mac), корпус проверки Mac (`Sources/SwitchValidation/Resources/corpus.json`) на раскладках Windows, движок ввода против симулятора Windows: очередь ввода, перехват, программа, которая применяет раскладку с опозданием или вовсе не применяет, детектор, отвечающий не сразу, и сотни случайных расписаний быстрого набора с перекрывающимися нажатиями. Каждое расписание должно дать тот же текст, что медленный набор.
- GitHub Actions (`.github/workflows/windows.yml`) на настоящей Windows: те же тесты, сверка таблиц раскладок с Windows и `yasno.exe --self-test` — настоящий перехват, SendInput и раскладки Windows против поля ввода: медленный, быстрый и «внахлёст» набор фраз.

## Выпуск

Mac-версия обновляется из последнего релиза GitHub (`releases/latest`). Windows-релизы поэтому публикуются с тегом `win-v…` и **без** отметки Latest. В релиз кладутся `yasno-<версия>-x64.exe`, `yasno-<версия>-x64.exe.sha256` (их ищет автообновление) и архив для людей — всё это собирает CI (артефакт `Yasno-windows-x64`).
