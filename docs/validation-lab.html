Ясно. Лаборатория ввода

Только локальные тестовые поля. Страница не отправляет запросы, не имитирует нажатия и не считает заполнение через JavaScript проверкой клавиатуры.

Сценарий

Ожидаемый текст:

Выберите сценарий, подготовьте поле и наберите физическими клавишами.

Раскладку переключайте вручную по инструкции. Для опечаток проверьте оба положения настройки «Исправлять опечатки». Ввод инструментами автоматизации может обходить системный перехват клавиатуры; такие результаты не подтверждают работу глобального переключателя.

Поля

Обработчик input ещё не вызывался

Парольное поле не читается проверкой, не попадает в отчёт и не регистрируется обработчиками страницы.

Смена фокуса и выделения

Начните слово в одном поле и продолжите в другом. Старый префикс не должен попадать в новое поле. Проверьте Shift со стрелкой, оба Shift, удержание Shift более 0,4 секунды, Backspace, переключение раскладки через меню, копирование и вставку.

Для проверки диапазонов вставьте в начале тестового поля 👩‍💻 привет, поставьте курсор после пробела и наберите следующее слово. Исправление не должно менять эмодзи, соседние слова или перенос строки.
