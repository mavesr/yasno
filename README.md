# Ясно

Небольшой переключатель раскладки для macOS 14+.
Создан под ABC, Russian и Ukrainian – Legacy, установленные на этом Mac.
Немецкий и английский используют общую ABC. Поддерживается и установленная German QWERTZ.

## Запуск

Готовое приложение: `/Users/mischa/Applications/Ясно.app`.

1. Откройте «Ясно».
2. Нажмите «Открыть настройки» и включите «Ясно» в **Универсальном доступе** и **Мониторинге ввода**.
3. Если macOS предложит перезапуск, завершите и снова откройте «Ясно».
4. Завершите Caramba. Пока она запущена, «Ясно» автоматически остаётся на паузе.
5. В браузерном поле выберите ABC и наберите `ghbdtn`: ожидается `привет` до пробела.
6. Для украинского приветствия через вашу Ukrainian Legacy наберите в ABC `ghsdbn`: ожидается `привіт` до пробела.

## Поведение

- С версии 0.2.3 раннее переключение распознаёт также уверенные начала слов: `bpex` → «изуч» до пробела. Требуются минимум четыре буквы и несколько частых продолжений в целевом языке; окончание не дописывается. Добавлены пропущенные `github` и «изучи»: `Пшерги` → `Github`, `bpexb` → «изучи». [Причины и проверки](docs/word-fixes-0.2.3.md).
- С версии 0.1.8 уверенно распознанная ошибка исправляется во время набора, до пробела, начиная с четырёх символов. Проверки объединяются с интервалом 35 мс; непрерывный набор не откладывает проверку до паузы. Если набранное ещё может быть началом правильного словарного слова текущего языка, раннее переключение пропускается. Пробел остаётся дополнительной проверкой для коротких и неоднозначных слов. Слово из двух-трёх букв, после которого набор остановился на 0,6 с, проверяется как законченное (в поле поиска пробела не бывает: «гыф» → «usa»), если оно не может стать началом слова текущего языка. Enter и Tab не запускают отложенное исправление.
- Адреса сайтов распознаются отдельно: `фссщгтеюфзздуюсщь` → `account.apple.com`, также поддерживаются поддомены, дефисы, цифры, HTTP(S), порт и путь. Проверяется синтаксис и зона по встроенному списку IANA; DNS и сеть не используются. Правильные адреса и адреса электронной почты сохраняются. [Изменения и проверка](docs/live-address-fixes.md).
- Четыре исходных частотных списка по 50 000 слов проходят проверку алфавита. RU/UK дополнительно проверены словарями LibreOffice/Hunspell и авторскими дополнениями; общие правильные слова сохраняются в обоих языках. Для слов от четырёх букв используется весь активный список.
- Известные правильные слова от четырёх букв сохраняются независимо от редкости. Для редких коротких сокращений требуется сильное частотное преимущество целевого слова. Подтверждённый украинский или русский контекст защищает редкие родные слова от такой замены.
- С версии 0.1.6 неизвестное словарю латинское составное слово тоже распознаётся: `фззыещку ` → `appstore `. Если точной словарной замены нет, проверяются две известные части одного языка (например, app + store, screen + shot). Такая проверка применяется только из кириллицы в латиницу и не переопределяет известные исходные слова. [Причина и проверка](docs/compound-fixes.md).
- Двухбуквенные слова исправляются при высокой уверенности: `zr ns` → «як ти». Для неоднозначных RU/UK вариантов учитываются до шести предыдущих слов в том же предложении и поле; затем — последняя вручную выбранная кириллическая раскладка. Без достаточных оснований замена пропускается.
- С версии 0.1.7 одиночные ошибочные буквы исправляются в настоящие односимвольные слова: при выбранном русском `z b f` → «я и а», при украинском `b` → «і». Для неоднозначных вариантов нужен контекст или выбранный язык. Правильные «я», «и», «а», английские `a` и `I` сохраняются; вручную Shift преобразует и их. `,hfepth` → «браузер», `фззсщттусе` → `appconnect`. [Изменения и проверка](docs/arc-word-fixes.md).
- Одно короткое нажатие и отпускание любого Shift в пустом поле переключает раскладки по кругу: ABC → Russian → Ukrainian → ABC. Для слова или выделения первое нажатие выбирает подходящий вариант, следующие перебирают все раскладки, включая русский и украинский варианты одинакового написания. После автоматической замены первое нажатие отменяет её, следующие продолжают полный круг. Ручное преобразование работает и с неизвестными словарю словами.
- С версии 0.2.1 короткий Shift преобразует и отдельные символы: `$` ↔ `%`, кавычки, знаки пунктуации и другие знаки обычного/Shift-слоя. Для недавно набранных знаков используется фактическая клавиша, чтобы одинаковые символы на разных клавишах преобразовывались точно. После замены буквы внутри слова преобразуется только свежий фрагмент. `gthtrk.xfkbcm` → «переключались». [Изменения и проверки](docs/manual-editing-fixes.md).
- С версии 0.2.2 украинский словарь дополнен 148 словоформами с апострофом: `ім'я`, `сім'я`, `п'ять`, `пам'ять`, `зв'язок` и др. Поддерживаются типографские варианты апострофа и обе украинские таблицы Apple. Неизвестное слово с внутренним апострофом тоже преобразуется вручную. Анализ выполняется на рабочей очереди; отпускание Shift после заглавной буквы больше не резервирует следующий ввод. [Исправления по аудиту и измерения](docs/audit-fixes-0.2.2.md).
- После слова с пробелом Shift преобразует предыдущее слово, включая правильные и неизвестные словарю слова. При быстром нажатии Shift программа ждёт, пока редактор подтвердит набранное слово. Поиск не переходит на предыдущую строку: в пустом поле или на новой пустой строке меняется только язык. Явное выделение позволяет преобразовать нужный текст; пунктуация внутри кириллической фразы сохраняется.
- Shift с буквой, стрелкой, другой клавишей или мышью выполняет обычное действие без смены языка. События Shift передаются приложению сразу: переключение проверяется только после отпускания. Удержание дольше 0,4 секунды, сочетание с Command/Control/Option/Fn и одновременное нажатие обоих Shift не переключают раскладку. Два отдельных коротких нажатия теперь означают два перехода.
- Код с цифрами/служебными символами и слова из нескольких букв в верхнем и смешанном регистре автоматически не преобразуются; для распознанных веб-адресов действует отдельная проверка. Обычные короткие английские и немецкие слова сохраняются.
- С версии 0.2.0 отдельный флажок «Исправлять опечатки» включает локальную проверку написания после пробела. Например: «првиет» → «привет», `helllo` → `hello`. Настройка сохраняется, её можно выключить независимо от переключения раскладки. При нескольких словарных кандидатах программа сохраняет ввод; короткий Shift отменяет последнюю замену.
- Пауза и исключение текущего приложения находятся в меню значка «Ясно». Исключения для слов — в окне приложения.
- Автозапуск по умолчанию выключен; он включается одним флажком.

## Конфиденциальность и совместимость

Приложение не содержит сетевых запросов, телеметрии, истории ввода и журналирования текста. Буфер обмена не используется. В памяти находятся текущее слово, последнее завершённое слово до начала следующего ввода или смены поля, ограниченный контекст из активного поля (до 256 единиц UTF-16) и данные последней замены для отмены. Соседний контекст не сохраняется между проверками. Ответы системного словаря macOS о проверенных словах кешируются в памяти до перехода в другое приложение или паузы. На диск записываются настройки, исключения и идентификатор предпочитаемой раскладки для приложения. Единственное исключение — диагностический режим `--trace-keys` (ниже), который запускается только вручную и пишет нажатия в файл на 30 секунд.

Защищённый ввод macOS приостанавливает обработку. Защищённые поля паролей не редактируются. Terminal, iTerm, 1Password и Keychain Access включены в исключения по умолчанию.

Приложение читает и выделяет точный диапазон через macOS Accessibility, затем вводит замену стандартным Unicode-событием клавиатуры. Буфер обмена не используется. Приложение проверяет фокус, позицию курсора и содержимое диапазона. Во время короткой операции входящие нажатия временно удерживаются и воспроизводятся с сохранением порядка символов, чтобы не затереть быстро набранное продолжение. Отпускание уже доставленной клавиши проходит сразу; накопленные пары нажатие/отпускание отправляются вместе, чтобы задержка интерфейса не превращала короткое нажатие в удержание. При смене окна/поля/раскладки или движении курсора старый буфер сбрасывается. Повторные системные уведомления без фактической смены поля или раскладки буфер не сбрасывают.

Очередь выпускает события последовательно: новые нажатия не обгоняют удержанные. Перед вводом замены клик отменяет подготовку; после отправки замены клик кратко ожидает её подтверждения, сохраняя порядок. При сбое доставки перехват приостанавливается и освобождает ввод. Замена проверяет начало слова и не преобразует дописанный суффикс внутри существующего слова. Если редактор не предоставляет чтение диапазона, чтение всего значения разрешается только для полей до 16 384 символов; координаты UTF-16 не расширяются через эмодзи.

С версии 0.1.5 системный перехват работает в отдельном потоке и не ждёт главный поток, Accessibility или браузер. Правильные слова, включая односимвольные, не запускают AX-редактирование. Ручное преобразование резервируется сразу при отпускании Shift; отпускание предыдущего пробела не отменяет его. [Причины и проверка исправлений ввода](docs/input-fixes.md).

С версии 0.1.7 при активации браузера запрашивается полное дерево Accessibility; фокус сначала читается через системный интерфейс с проверкой владельца элемента, затем через приложение. Это учитывает браузеры с отдельной оболочкой, такие как Arc.

Некоторые веб-редакторы (включая отдельные нестандартные редакторы документов) могут не предоставлять нужный интерфейс Accessibility. В таком поле приложение пропустит исправление; оно не будет перезаписывать всё содержимое поля. Совместимость с конкретными сайтами требует проверки в браузере пользователя.

Версия 0.1.4 исправляет подтверждённые замечания аудита. Прошли 46 автоматических тестов и системные проверки Chrome, включая 12 быстрых прогонов смешанной фразы. [Изменения и проверка аудита](docs/audit-fixes.md), [история проверок](docs/test-report.md). Это не доказывает отсутствие ошибок во всех приложениях и сложных веб-редакторах.

## Сборка

Нужны Xcode / Swift 5.10+ и macOS 14+.

```sh
swift test
./scripts/build.sh
```

Результат: `dist/Ясно.app`. Без `YASNO_SIGNING_IDENTITY` скрипт сам берёт единственный сертификат Apple Development из Связки ключей; если их нет или несколько, он останавливается. `YASNO_SIGNING_IDENTITY=-` включает ad-hoc подпись, после которой macOS снова спросит разрешения. Стабильная подпись важна для сохранения разрешений после обновления. Локальная сборка подписана имеющимся Apple Development сертификатом. Для передачи другим пользователям есть отдельная универсальная сборка с Developer ID и нотарификацией: [сборка DMG](docs/distribution.md).

```sh
./dist/Ясно.app/Contents/MacOS/Yasno --diagnose
```

Диагностика выводит только число слов, установленные раскладки и состояние разрешений, без пользовательского текста.

```sh
open -n -W -a "Ясно" --args --trace-keys
```

Трассировка клавиш нужна, когда ввод не доходит до перехватчика (удалённые рабочие столы). 30 секунд она пишет каждое нажатие с кодом клавиши, флагами и набранным символом в `~/Library/Logs/Yasno-keys.txt`, затем показывает файл в Finder. Это единственный режим, в котором набранный текст попадает на диск; удалите файл после использования.

## Большая система тестирования

```sh
./scripts/validate.sh quick
./scripts/validate.sh full
```

Независимый корпус из 1 133 слов четырёх языков, сотни тысяч генеративных
проверок, опечатки во всех позициях, физические клавиши, очередь, фокус,
безопасная замена, Unicode и словари. Отчёт разделяет обязательные ошибки,
пропущенные исправления и неоднозначные варианты. Есть повтор одного сценария
по ID и сравнение прогонов с защитой от незаметной смены эталона.

[Как запускать и читать результаты](docs/validation-system.md).
Для физического набора в браузере: [локальная лаборатория](docs/validation-lab.html).
